# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub: open the repository's
**Security** tab and choose **Report a vulnerability**. Do not open a public
issue.

Include the helmcov version, how to reproduce the problem, and its impact. You
will get an acknowledgement within five working days, and updates as the report
moves to a fix and a release.

## Supported versions

Only the latest release gets security fixes. The GitHub Action follows the `v1`
tag, which moves to each new release.
